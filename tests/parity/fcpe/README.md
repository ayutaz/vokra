# FCPE official-reference fixture

These files were generated by `tools/parity/fcpe_dump_reference.py` through
the official `torchfcpe==0.0.4` PyPI wheel and its bundled
`fcpe_c_v001.pt`. They pin three independent boundaries for the exact same
PCM16 input:

- `mel.f32`: official `Wav2MelModule`, `[33, 128]`;
- `latent.f32`: official sigmoid classifier, `[33, 360]`;
- `f0.f32`: official public local-argmax inference output, `[33]`.

All arrays are headerless little-endian row-major `f32`. `meta.json` records
the source wheel/checkpoint hashes, dependency versions, shapes, and every
fixture hash. The public waveform-to-F0 wrapper's explicit/default threshold
is `0.006`; the lower-level decoder's standalone `0.05` default is not the
public inference path.

The 43 MB GGUF is intentionally not committed. Run the Rust parity leg with:

```sh
VOKRA_FCPE_REAL_GGUF=/path/to/strict-fcpe.gguf \
  cargo test -p vokra-models fcpe_official_torchfcpe_v001_parity -- --nocapture
```

Per repository policy, run that `vokra-models` command on VAST rather than on
the maintainer Mac.
